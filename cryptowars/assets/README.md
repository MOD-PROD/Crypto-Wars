# CryptoWars character assets

Import the original character pack here. Each faction directory contains `portrait.png` and its original animated GIF or WebP. The manifest maps faction IDs to source files.

Faction IDs: ton, btc, eth, sol, xmr, trx, diamond, club, heart, spade.

These are source assets, not VCMI battle animations. Preserve the original files. Battle animation groups, directional sprites and in-engine validation are required before enabling the CryptoWars expansion. Start with TON and BTC.
